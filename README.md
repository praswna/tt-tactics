# TT Tactics

탁구 전략을 시각적으로 그려 보여주고, 구(球)마다 왜 그렇게 치는지 설명하는 앱.

현재 상태: **개념 검증 프로토타입(v0.2)**. 전술 하나("서브 후 3구 공격: 돌아서기 → 포핸드 → 스텝 → 포핸드 루핑")를 데이터로 적고, **3D 입체 뷰**와 2D 탑뷰에서 구 단위로 재생하며 설명을 보여준다. 3D에서는 마네킹 선수가 발을 하나씩 옮기고, 발자국과 스텝 순서 번호가 바닥에 남는다.

## 바로 보기

`prototype/index.html`을 브라우저에서 열면 된다. 서버가 필요 없다.

- "3D 입체 / 2D 탑뷰" 토글. 3D는 드래그로 회전, 휠/핀치로 확대, 카메라 프리셋(뒤에서 · 내 발 클로즈업 · 옆에서 · 위에서 · 상대 쪽)
- 1구~5구 버튼 또는 ← → 키로 이동, 스페이스로 전체 재생
- "전체 보기"로 모든 구를 한 그림에
- 4구 분기(A: 포핸드 사이드로 블록 / B: 백쪽으로 블록)를 바꿔 가며 비교

## 구조

| 경로 | 내용 |
|---|---|
| `docs/DESIGN.md` | 설계 문서: 개념 모델, 시각화, 화면, 에디터, 스키마, 기술 스택, 로드맵 |
| `schema/tactic.ts` | 전술 데이터 모델 타입 정의 |
| `tactics/*.json` | 전술 데이터(원본) |
| `prototype/index.html` | 단일 파일 프로토타입. 전술 JSON을 내장 |
| `scripts/embed-tactic.mjs` | JSON을 고친 뒤 HTML 내장 복사본 갱신: `node scripts/embed-tactic.mjs` |

## 핵심 아이디어

- 전술은 선형 시퀀스가 아니라 **상대 반응에 따라 갈라지는 트리**다. 데이터도 그렇게 저장한다.
- 좌표는 **미터 단위, 실제 테이블 비율**. 풋워크 거리를 그대로 설명에 쓴다.
- 구마다 설명은 **무엇을 / 왜 / 체크포인트 / 흔한 실수** 네 칸.
- 발 위치는 저장하지 않고 **풋워크 종류(피벗, 크로스오버, 사이드스텝 …)에서 스텝 순서를 계산**한다.

3D 뷰는 Three.js를 cdnjs에서 받으므로 인터넷 연결이 필요하다.
